# StudyNova Product Plan

## Goal

Build a mobile academic coach that helps students plan study time, revise consistently, and gives parents a clear progress view.

## MVP Roles

- Student: enters subjects, topics, pages, available study time, and exam date.
- Parent: views linked student progress, consistency, and latest academic updates.

## MVP Features

- Student onboarding
- Smart study plan calculation
- Personalized timetable preview
- Spaced-repetition revision schedule
- Daily check-ins
- Parent progress dashboard
- Android Play Store release path

## Future Versions

- Supabase Auth and PostgreSQL persistence
- Parent invite codes
- WAEC/JAMB preparation mode
- Teacher dashboard
- AI study recommendations
- School-wide academic analytics
- iOS app

## Delivery Phases

1. Foundation: repository, Codespaces, API, mobile shell.
2. Planner: study calculation, timetable generation, revision schedule.
3. Accounts: student and parent authentication.
4. Tracking: check-ins, streaks, completion metrics.
5. Launch: testing, Play Store assets, privacy policy, closed testing.
