## Full Description

```text
StudyNova helps students turn exam preparation into a clear daily study plan.

Students enter their class, exam dates, subjects, topics, pages, study resources, and reading pace. StudyNova then creates a timetable that shows what to study each day, how much time is needed, and how close the student is to exam day.

For students:
- Build a study plan from subjects, topics, pages, and exam dates.
- See daily study sessions, revision blocks, and practice tasks.
- Mark study sessions as done with recall notes and confidence checks.
- Track missed sessions and rebalance the plan when study falls behind.
- Set local study reminders and missed-session nudges.
- Use light or dark mode while studying.

For parents and guardians:
- Create a separate parent account.
- Link one or more student accounts with invite codes.
- Monitor completed sessions, study minutes, missed sessions, and recall notes.
- Encourage progress without needing to guess what was studied.

StudyNova is built for students, parents, guardians, and schools that want a calmer way to organize exam preparation. It does not replace teachers, textbooks, or school guidance. It gives students a structured study rhythm and gives parents a clearer view of progress.

Current closed-test features include student accounts, parent accounts, parent-student linking, generated study plans, daily progress tracking, reminders, missed-session catch-up, account recovery support, and account deletion requests.
```

Full description character count target: under 4,000.

## Feature Graphic Brief

Required size: 1024 x 500 px.

Concept: Calm academic planning for students and parents.

Visual direction:

- Use StudyNova's calm academic palette: royal blue, teal, white/light background, and deep navy text.
- Show a clean study dashboard/timetable preview and a subtle parent progress card.
- Keep the StudyNova name visible but not oversized.
- Use one clear value line only: "Plan smarter. Study steadier."
- Keep important text and UI elements centered so the image works when cropped.
- Avoid badges, pricing, rankings, excessive text, school-specific branding, or claims that imply official school ownership.

Suggested layout:
