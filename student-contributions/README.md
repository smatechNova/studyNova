# StudyNova Student Contribution Pack

This folder is for safe frontend contributions from students.

Each student owns only their named folder:

- `Alliyyah/`
- `Mutmainnah/`
- `Zainab/`
- `Ameerah/`
- `Rahmah/`
- `Alhassan/`

Rules:

1. Work only inside your own folder.
2. Do not edit `apps/api`.
3. Do not edit `package.json` or `package-lock.json`.
4. Do not push directly to `main`.
5. Create a branch, commit your work, push the branch, and open a Pull Request.

These files are not connected to the live StudyNova app yet. They are safe contribution tasks. After review, selected ideas can be moved into the production frontend.
